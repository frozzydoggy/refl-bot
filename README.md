# REFL Bot

Discord.js REFL league bot.

## Railway variables
- TOKEN
- CLIENT_ID
- GUILD_ID
- DATA_DIR (recommended when using a Railway Volume)

If using a Railway Volume mounted at `/data`, set `DATA_DIR=/data`.
The JSON files in `data/` are seed files; live data is stored in `DATA_DIR` when configured.

## Commands
- /addteam
- /checkteaminfo
- /editteaminfo
- /d1table
- /d2table
- /result
- /addplayer
- /changeplayerteam
- /checkplayerstats
- /addplayerstats
- /funds
